# EMIQEN Brand and Visual Design

## Brand essence
EMIQEN is a modern AI product concept for voice-and-text interaction, enterprise task support, and Indian-context language handling. The visual identity should feel precise, capable, trustworthy, and distinctly technology-oriented without looking like a generic crypto or gaming site.

## Logo
Use the supplied EMIQEN brand-board image as visual reference. The mark combines:
- An abstract, angular “E” / hexagon-like form
- A blue-to-cyan upper sweep
- A deep navy core
- Violet accents
- A compact sound-wave motif

Use the actual approved logo file if available. If only the reference board is available, extract or recreate a clean vector mark only if the design tools can do so faithfully; do not use the entire brand board as the header logo. Keep the logo aspect ratio intact and provide clear space around it.

## Official reference palette
- Deep Navy: `#071B3A`
- Royal Blue: `#1769F8`
- Cyan: `#00D4E8`
- Electric Violet: `#6D28D9`
- White: `#FFFFFF`

Suggested UI tokens:
- Primary text: `#071B3A`
- Primary action: `#1769F8`
- Accent/highlight: `#00D4E8`
- Secondary accent: `#6D28D9`
- Main page background: `#FFFFFF`
- Soft section background: `#F5F8FF`
- Muted text: a legible slate/navy shade with sufficient contrast
- Borders: pale cool grey-blue

Use the supplied five-color palette as the identity anchor. The soft backgrounds and border colors above are supporting UI neutrals, not replacements for the official palette.

## Typography
- Preferred family: Montserrat, especially Bold/Semibold for headings and Regular/Medium for body text.
- Use a reliable sans-serif fallback.
- Strong hierarchy: large concise headline, readable body copy, clear section headings, short labels.
- Avoid tiny body text and excessive all-caps.

## Visual direction
- White and very light blue sections balanced with deep-navy panels.
- Selective blue/cyan/violet gradients inspired by the logo, used for focal elements rather than every section.
- Subtle waveforms, connected nodes, abstract conversation lines, or flowing signal motifs may be used as original background graphics.
- Generous whitespace, strong alignment, rounded cards, thin borders, restrained shadows.
- Use polished product mockups only when they illustrate an actual planned interface; label prototype visuals as illustrative.
- Use authentic UI details rather than stock photos of robots, glowing brains, or generic office people.

## Logo usage
- Prefer full-color logo on white/light backgrounds.
- Use the light/white logo variant on deep navy only if an approved version exists.
- Maintain legibility at small sizes; use icon-only mark for compact mobile/navigation use only if it remains recognizable.
- Never stretch, skew, rotate, recolor arbitrarily, or add effects that conflict with the logo.

## Motion
- Short fades, gentle scroll reveals, subtle waveform movement, and small hover transitions are acceptable.
- Respect `prefers-reduced-motion`.
- Avoid parallax that harms usability, constant motion, flashing, and animations that delay access to content.
